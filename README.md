# TabRevive

TabRevive is a Chrome extension (Manifest V3) that keeps chosen tabs behaving as if they were in the foreground: the page cannot tell you switched away, its timers and animations keep running at full speed, and Chrome will not discard it.

## How it works

A tab is *protected* when you toggle it in the popup, press the shortcut, or it is on a site you marked "always keep active". For a protected tab:

| Layer | What it does |
|---|---|
| `chrome.tabs.update({ autoDiscardable: false })` | Chrome will not discard the tab under memory pressure. |
| `injected.js` (page's main world, every frame, `document_start`) | `document.hidden`, `visibilityState` and `hasFocus()` report visible/focused. Events caused only by leaving or returning (`visibilitychange`, window `blur`/`focus`, pointer leaving the page, `freeze`/`resume`) are swallowed by one capture listener. While the tab is really hidden, `setTimeout`, `setInterval` and `requestAnimationFrame` are driven by ticks from the extension instead of Chrome's throttled timers. |
| `src/offscreen/` | An extension-owned worker that produces those ticks. It lives outside the page, so a site's CSP cannot block it. |
| `content.js` (isolated world) | Asks the background whether the tab is protected and relays commands and ticks to `injected.js` over a private, randomly named DOM event channel. |
| `armed.js` | Registered for hosts that have protected tabs, so protection is on before the page's first script runs (for example on auto-refresh while hidden). |

The shim is installed on every page but stays inert unless the tab is protected. It deliberately leaves clocks (`Date`, `performance.now`), media elements, in-page focus/blur, fullscreen and `IntersectionObserver` untouched.

Patched functions report native source, names and lengths, nothing is added to `window`, and no extension resource is web-accessible.

## Project layout

```
manifest.json
LICENSE
icons/                         toolbar/store icons (16, 32, 48, 128) and logo.svg used in the popup and settings headers
src/
  background/background.js     service worker: owns all state, site rules, restart recovery, auto refresh, shortcuts
  content/injected.js          page shim (main world, every frame, document_start)
  content/content.js           isolated-world bridge between the extension and the shim
  content/armed.js             registered per protected host so protection is on before the page's first script
  offscreen/offscreen.html|js  offscreen document that relays timer ticks to protected tabs
  offscreen/ticker.js          the worker that produces the ticks
  popup/popup.html|css|js      toolbar popup
  settings/settings.html|css|js  options page (saves instantly)
  shared/ui.css|js             themes, custom background, toast, shared by popup and settings
_locales/                      translations (generated by tools/locales.mjs, don't edit by hand)
store/listing.md               Chrome Web Store copy, permission justifications, privacy answers
store/listing-translations.md  translated store descriptions for the dashboard
store/images/                  store screenshots and promo tiles (tools/store-images.mjs)
tests/harness.mjs, probe.html  end-to-end test (real Chromium, real tab switches)
tools/locales.mjs              all translated strings in one table; run it to regenerate _locales
tools/store-images.mjs         renders store/images from the real extension UI
website/                       tabrevive website (Next.js, static export)
```

Load unpacked from the repository root at `chrome://extensions`.

## Testing

```
node tests/harness.mjs            # core checks, about a minute
node tests/harness.mjs --sites    # plus 8 real websites
node tests/harness.mjs --long     # plus a 6-minute hidden-tab run
```

Needs Node 22+ and a Chromium build that allows `--load-extension` (Chrome for Testing; set `CHROME=/path/to/binary` if it is not Playwright's copy). No npm install.

## Website

```
cd website
npm install
npm run dev        # local preview
npm run build      # static site in website/out/
```

Set `SITE_URL` to the real domain when building (used for the sitemap and canonical links), and replace `EXTENSION_ID` in `website/lib/site.js` with the extension's store ID. `website/out/` can be hosted anywhere static: GitHub Pages, Cloudflare Pages, Netlify. If it's served from a sub-path (like `username.github.io/tabrevive`), build with `BASE_PATH=/tabrevive`.

## State

`chrome.storage.local`, written only by `background.js` (through a queue, so concurrent events cannot lose updates):

- `alwaysActiveTabs` — protected tabs by tab id (`auto: true` when added by a site rule)
- `alwaysActiveSites` — hostnames protected automatically
- `pendingRestore` — URLs of manually protected tabs from before a browser restart; each reclaims protection when it reloads
- `extensionSettings`, `extensionStats`

Theme, background and dim level live in `localStorage` of the extension pages.

## Settings that change behaviour

- **Aggressive Mode** — the unthrottled timers and animation frames. Off = only visibility/focus spoofing and discard protection.
- **Enable Silent Audio** — holds a silent audio stream open in protected tabs.
- **Simulate Activity** — a synthetic mouse move every 30 s, for sites with their own idle timers (off by default).
- **Maximum Active Tabs**, **Enable Notifications**, **Auto Refresh**.

## Known limits

- Things Chrome itself stops in hidden tabs cannot be faked from a page script: rendering, CSS animations and transitions, `IntersectionObserver` callbacks.
- Leaving fullscreen by switching tabs still fires `fullscreenchange`.
- Synthetic events (`Simulate Activity`) have `isTrusted === false`.
- Chrome's Energy Saver / Memory Saver can freeze a background tab entirely; no page script runs then.
- Pages the browser forbids extensions on (`chrome://`, the Web Store) cannot be protected.
- Nothing leaves the browser: no network requests, no analytics.
